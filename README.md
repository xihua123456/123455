# 西安建筑科技大学吧友交流群 · 《群史记》

本项目基于《西安建筑科技大学吧友交流群》（群号：785195242）自 2023 年 12 月至 2026 年 8 月共 **351,685 条真实聊天记录**，通过深度数据蒸馏、人物画像性格建模与拓扑关联网分析，构建了一部集**纪传体史记、编年大事记、每日实录简记、交互式人物关系网络、全景目录与即时搜索**于一体的群史互动网页。

## 快速使用
直接在文件夹中**双击 index.html**，即可在任意浏览器中流畅浏览！无需联网，零依赖。
